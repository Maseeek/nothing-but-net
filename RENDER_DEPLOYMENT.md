# Render Deployment Guide for NothingButNet Backend (FREE TIER)

This guide provides step-by-step instructions to deploy the NothingButNet backend services on Render using the **FREE tier**.

## Architecture Overview

The backend consists of two services (both on FREE tier):
1. **Node.js API Server** (port 3000) - Handles authentication, user management, and session data
2. **Python Video Processor** (port 5000) - Processes basketball shot videos and performs analysis

Both services are configured to use Render's **free tier** (`plan: free` in render.yaml).

## Prerequisites

Before deploying, ensure you have:

1. A [Render](https://render.com) account (**FREE** - no credit card required)
2. A MongoDB database:
   - Recommended: [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) **FREE tier (M0)** - 512 MB storage
   - Get your connection string (format: `mongodb+srv://username:password@cluster.mongodb.net/dbname`)
3. Email credentials for sending verification emails:
   - Gmail recommended (FREE)
   - Create an [App Password](https://support.google.com/accounts/answer/185833) (not your regular Gmail password)
4. This repository pushed to GitHub

## Deployment Methods

### Method 1: Using Render Blueprint (Recommended - FREE)

The repository includes a `render.yaml` file that automates the FREE tier deployment.

1. **Connect Repository to Render:**
   - Go to [Render Dashboard](https://dashboard.render.com/)
   - Click "New +" → "Blueprint"
   - Select "Connect a repository"
   - Choose your GitHub repository containing this code
   - Render will detect the `render.yaml` file automatically
   - Both services will be created on the **FREE tier**

2. **Configure Environment Variables:**
   
   When prompted, set these environment variables:

   **For nbnc-backend service (FREE tier):**
   ```
   MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/nbn
   EMAIL_USER=your-email@gmail.com
   EMAIL_PASS=your-gmail-app-password
   FRONTEND_URL=https://your-frontend-url.com
   ```
   
   **For nbnc-video-processor service (FREE tier):**
   ```
   MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/nbn
   ```

   Note: `JWT_SECRET` will be auto-generated by Render for security.

3. **Deploy:**
   - Click "Apply" to create and deploy both services on FREE tier
   - Wait for the build and deployment to complete (5-10 minutes)
   - Both FREE tier services will receive unique URLs like:
     - `https://nbnc-backend-xxxx.onrender.com`
     - `https://nbnc-video-processor-xxxx.onrender.com`

### Method 2: Manual Deployment (FREE Tier)

If you prefer to deploy services individually on the FREE tier:

#### Deploy Node.js Backend (FREE)

1. Go to [Render Dashboard](https://dashboard.render.com/)
2. Click "New +" → "Web Service"
3. Connect your GitHub repository
4. Configure:
   - **Name:** `nbnc-backend`
   - **Runtime:** Node
   - **Plan:** Select **"Free"** (important!)
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Environment Variables:**
     - `PORT=3000`
     - `NODE_ENV=production`
     - `MONGODB_URI=your-mongodb-connection-string`
     - `JWT_SECRET=your-secure-random-secret`
     - `EMAIL_USER=your-email@gmail.com`
     - `EMAIL_PASS=your-email-app-password`
     - `FRONTEND_URL=your-frontend-url`

5. Click "Create Web Service"

#### Deploy Python Video Processor (FREE)

1. Go to [Render Dashboard](https://dashboard.render.com/)
2. Click "New +" → "Web Service"
3. Connect your GitHub repository
4. Configure:
   - **Name:** `nbnc-video-processor`
   - **Runtime:** Python 3
   - **Plan:** Select **"Free"** (important!)
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python src/server/server.py`
   - **Environment Variables:**
     - `PORT=5000`
     - `MONGODB_URI=your-mongodb-connection-string`

5. Click "Create Web Service"

## Post-Deployment Configuration

### 1. Update Frontend Environment Variables

After deploying the backend services, update your frontend deployment with the new backend URLs:

```env
VITE_API_BASE_URL=https://nbnc-backend-xxxx.onrender.com
VITE_ANALYSIS_API_URL=https://nbnc-video-processor-xxxx.onrender.com
```

### 2. Update CORS Settings

Make sure the `FRONTEND_URL` environment variable in your backend matches your actual frontend URL for proper CORS configuration.

### 3. Test Your Deployment

Visit your backend URL to verify it's running:
```
https://nbnc-backend-xxxx.onrender.com/
```

You should see: "Server is running 🚀"

## Environment Variables Reference

### Required Variables

| Variable | Service | Description | Example |
|----------|---------|-------------|---------|
| `MONGODB_URI` | Both | MongoDB connection string | `mongodb+srv://user:pass@cluster.mongodb.net/nbn` |
| `JWT_SECRET` | Backend | Secret for JWT tokens | Auto-generated or custom secure string |
| `EMAIL_USER` | Backend | Email address for sending emails | `your-email@gmail.com` |
| `EMAIL_PASS` | Backend | Email app password | Gmail app password |
| `FRONTEND_URL` | Backend | Frontend URL for CORS and email links | `https://your-frontend.com` |

### Optional Variables

| Variable | Service | Description | Default |
|----------|---------|-------------|---------|
| `PORT` | Both | Server port | 3000 (backend), 5000 (video) |
| `NODE_ENV` | Backend | Node environment | `production` |
| `PRODUCTION_FRONTEND_URL` | Backend | Additional CORS origin | None |

- **Monthly Usage:** 750 hours/month per service (sufficient for most projects)
- **No Persistent Disk:** Use external storage or databases for persistence

💡 **Tips for FREE Tier:**
- Services are perfect for development, testing, and hobby projects
- MongoDB Atlas M0 (FREE tier) provides 512 MB storage
- Keep services active by pinging them periodically if needed
- All services remain completely FREE forever

### MongoDB Atlas Setup (FREE Tier)

1. Create a **FREE M0 cluster** at [MongoDB Atlas](https://www.mongodb.com/cloud/atlas)
2. Create a database user with password
3. Whitelist Render's IP addresses (or use `0.0.0.0/0` for all IPs)
4. Get your connection string from "Connect" → "Connect your application"
5. Replace `<password>` with your database user password
6. Replace `<dbname>` with `nbn` or your preferred database name

**FREE M0 Cluster includes:**
- 512 MB storage
- Shared RAM
- No credit card required
- Perfect for development and small projects

### Gmail Setup (FREE)

1. Enable 2-Factor Authentication on your Google account
2. Go to [App Passwords](https://myaccount.google.com/apppasswords)
3. Generate a new app password for "Mail"
4. Use this 16-character password as `EMAIL_PASS`

### Security Best Practices

- Never commit `.env` files or secrets to Git
- Use strong, randomly generated JWT secrets
- Regularly rotate secrets and passwords
- Monitor your Render dashboard for unusual activity
- Use MongoDB Atlas IP whitelisting when possible

## Troubleshooting

### Service Won't Start

1. Check the logs in Render Dashboard
2. Verify all environment variables are set correctly
3. Ensure MongoDB connection string is valid
4. Check that the database name matches in both services
5. Confirm you selected the **FREE** plan during setup

### CORS Errors

1. Verify `FRONTEND_URL` matches your actual frontend URL exactly
2. Include protocol (https://) in the URL
3. Check Render logs for CORS error messages

### Email Not Sending

1. Verify Gmail App Password is correct (not regular password)
2. Check that 2FA is enabled on Gmail account
3. Review Render logs for email sending errors

### Database Connection Failed

1. Verify MongoDB Atlas connection string format
2. Check that IP whitelist includes `0.0.0.0/0` or Render's IPs
3. Ensure database user has proper permissions
4. Test connection string using MongoDB Compass

### Service Spinning Down (FREE Tier)

This is normal behavior for FREE tier services:
1. Services automatically spin down after 15 minutes of inactivity
2. First request after spin down takes 30-50 seconds (cold start)
3. Subsequent requests are fast until next spin down
4. This is a feature of FREE tier, not a bug

**Solutions:**
- Accept the cold start delay (perfectly fine for development/hobby projects)
- Implement a periodic ping to keep services active
- This behavior is expected and normal for FREE tier
